核心产品矩阵

Chert 燧石启动器

内测中 · 2.6.0

硬核的 Minecraft 启动终端。内置 P2P 打洞联机、自愈 HUD 与四套 UI 设计语言。

Granite 极客开服器

核心开发中

坚如花岗岩的服务端管理面板。一键拉取核心、可视化编辑配置与崩溃自动重启。

Basalt 虚拟磁盘

核心开发中

坚如磐石的现代虚拟磁盘管理器。完美支持 VHDX / VMDK，原生只读挂载与安全快照。

Pumice P2P 联机网关

概念规划中

基于自研 UDP 打洞技术的纯本地联机利器。脱离启动器限制，任何 TCP/UDP 端口一键映射。

Cobalt 化学实验室

核心开发中

以深邃钴蓝为灵感的化学模拟工具。可视化反应过程与试剂操作，让实验安全且反复进行。

Geode 开发者浏览器

概念规划中

基于 Rust 打造的极简浏览器，内置本地预览服务器与开发网站纯净模式。

MicroDOS 微操作系统模拟

Vintage / Legacy

这是 RLRS Studio 的最初起点。用纯粹的 Windows 批处理脚本（.bat）构建的 DOS 命令行模拟器。没有现代框架，没有面向对象，只有最底层的逻辑堆砌与纯粹的热爱。虽然简陋，但它是一切极客魔法的原点。
