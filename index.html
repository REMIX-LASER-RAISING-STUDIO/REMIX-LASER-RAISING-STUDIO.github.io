产品矩阵

以岩石与结晶为名，构筑属于极客的数字宇宙。

⛏️

Chert 燧石启动器

Game Tool / Active

硬核的 Minecraft 启动终端。内置 P2P 打洞联机、自愈 HUD 与四套 UI 设计语言，超 300 次严苛提交。

已发布 · 2.5.6→
🖥️

Granite 极客开服器

Server Tool / In Dev

坚如花岗岩的服务端管理面板。无缝对接 Chert 的 P2P 穿透，一键开服、配置可视化、插件依赖检测。

核心开发中
💽

Basalt 虚拟磁盘

System Utility / In Dev

坚如磐石的现代虚拟磁盘管理器。完美支持 VHDX / VMDK，原生只读挂载与安全快照，绝不弄坏镜像。

核心开发中
🧪

Cobalt 化学实验室

Simulation / In Dev

以深邃钴蓝为灵感的化学模拟工具。可视化反应过程与试剂操作，让实验安全且反复地在屏幕上进行。

核心开发中
💎

Geode 晶洞浏览器

Web Browser / Planning

外表是石头，打开是晶洞。追求极致的轻量与纯粹，打造一个毫无臃肿插件、拒绝隐私追踪的浏览器。

概念规划中
📊

Quartz 系统监视器

Performance / Planning

像石英一样精准的性能看板。极低占用的 CPU/GPU/网络监控，原生支持现代暗黑 UI 与自定义悬浮窗。

概念规划中

MicroDOS 微操作系统模拟

Pure Batch Script / Origin

这是 RLRS Studio 的最初起点。用纯粹的 Windows 批处理脚本（.bat）构建的 DOS 命令行模拟器。没有现代框架，没有面向对象，只有最底层的逻辑堆砌与纯粹的热爱。虽然简陋，但它是一切极客魔法的原点。

本地优先 / 无服务器

我们相信最好的云就是不需要云。所有数据存在本地，P2P 直连不经过第三方服务器，你的数据只属于你。

拒绝臃肿

痛恨那些塞满广告和弹窗的流氓软件。所有的功能都经过精心编排，只为提供最纯粹的极客体验。
