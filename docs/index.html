Chert CLI 命令行指南

燧石启动器内置了完全对齐 GUI 的 CLI 工具，支持自动化脚本、服务器批量启动与静默更新。

# 查看当前所有已安装的版本
chert list

# 静默启动指定版本（跳过启动器 UI）
chert launch --version 1.20.4

# 导出崩溃日志并提取聊天记录为 Markdown
chert crash export --md --output=./logs/

# 以 JSON 格式输出当前配置
chert config --json

节日特效接入指引

官网使用的 /festival-fx.js 采用纯前端 Canvas 渲染，零依赖。目前支持中秋（月兔）、春节（鞭炮）等数十种节日识别。

// 强制预览中秋特效
localStorage.setItem('chert-fx-mode', 'midautumn');
location.reload();
