# MicroDOS：用尽一生知识的纯 BAT 艺术

在拥有 C# 和 19 亿 Token 之前，我曾用一个 `.bat` 文件，硬生生敲出了一个「操作系统」。

整理旧硬盘时，翻出一个叫 **微数 v25.0 BETA.bat** 的文件。

双击运行，黑色控制台弹出来，闪烁的绿色光标把我拉回了那个年代。

## 一个文件，装下一个系统

MicroDOS（微数）是纯批处理脚本写的「微型操作系统」。

今天写一个功能，第一反应是找框架、装依赖、建数据库。那时候不行——没有数据库，没有面向对象，没有一个第三方库，只有一门用 `goto` 和 `if` 表达一切的语言，和一台随时可能被家长关机的电脑。

于是所有「现代软件的基本件」，都被迫用字符串和文本文件重造了一遍。

### 账号系统：用 ini 当数据库

用户表就是一个文本文件 `urini.ini`：

```ini
[admin]
pass=****
level=2

[user1]
pass=****
level=1
```

登录逻辑用 `findstr` 做匹配：

```bat
findstr /b /c:"%user%" "%udir%\urini.ini" >nul
if errorlevel 1 goto login_fail
```

注册就是在文件末尾追加一段，删除用户是重写整个文件（把匹配到的行过滤掉），管理员重置密码是把对应段落的值改掉。

一个没有 SQL、没有索引、没有事务的数据库。它在几十个用户以内工作得很好——因为它永远不会有几十个用户。

### 插件化生态：扫描文件夹就是插件系统

主菜单启动时会遍历 `mod` 目录，把里面所有的 `.bat` 列成菜单项。

丢一个新的脚本进去，重启系统，它就成了系统的一部分。

今天这叫「插件热发现」，当年叫「`for %%i in (mod\*.bat) do echo %%i`」。原理一样：**约定大于配置**，一个文件夹就是注册表。

### 危险的极客工具

内置了两个现在绝对不敢再写的工具：

| 工具 | 行为 |
| --- | --- |
| KillDisk | 往磁盘写满数据，瞬间毁掉整个硬盘 |
| KMS 激活 | 直接调用系统底层命令跑激活代码 |

前者是真的危险，后者是真的灰。那时候不懂什么叫「不可逆」，只觉得能让机器听自己的话很酷。

现在写任何涉及删除的功能，第一反应都是备份、二次确认、回收站。

### 备忘录与全盘搜索

备忘录是最朴素的那种：命令行输入文字，`>>` 追加到 txt，没有任何格式。

全盘搜索是遍历所有盘符：

```bat
for %%d in (C D E F) do (
  if exist %%d:\ (
    dir /s /b "%%d:\*%keyword%*" 2>nul
  )
)
```

慢到可以泡一杯茶。但它是那个年代我能接触到的、唯一能「穿透整个文件系统」的东西。

## 彩蛋：114514

在菜单里输入 `114514`，屏幕会刷出一个巨大的字符画框，里面是一段英文：

```text
Congratulations on discovering the egg.
This program has used up all my life's knowledge.
I hope it can help you. May you have a happy life.
-----by:REMIX
```

翻译过来：

> 恭喜你发现了彩蛋。
> 这个程序用尽了我一生的知识。
> 希望它能帮到你，祝你生活愉快。
> —— REMIX

「用尽了一生的知识」这句话，当时写下去是认真的。

那年我把自己能掌控的所有计算机底层知识——文件系统、进程、批处理语法、文本解析、菜单状态机——毫无保留地塞进了这个简陋的黑框里。那不是修辞，那是一个少年当时能力的全部库存。

## 那个打错 `@echo off` 的少年

第一次写批处理的时候，我把 `@echo off` 打成了 `@//echo/ off`。

屏幕上满屏的命令回显，我还以为这就是「程序在运行」。

从那个错误开始，到能写出一门带账号、插件、搜索、彩蛋的「操作系统」，中间隔着的不是天赋，是无数个「为什么它不按我想的跑」。

MicroDOS 没有 bug 修复机制，没有现代化 UI，甚至连输入错误都会直接闪退。它的所有缺陷，都是那个年纪的真实水平。

但它证明了一件比技术更重要的事：**一个人在没有工具的时候，愿不愿意用最笨的方式把想法做出来。**

## 它完成了历史使命

微数静静地躺在历史的代码分支里，跑不动了，也没必要再跑。

而当年驱动它的那点东西——想让机器做一件本来做不到的事——一直没变。它现在驱动的是 C# 里的多线程、P2P 打洞、HUD 自愈，也许某天会是别的东西。

工具会换，语言会换，那股劲不能换。

> 极客的魔法，从来不是技术本身，是在没有魔杖的时候，非要用一根木棍把火点起来的那股倔。
