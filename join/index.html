加入极客基地

我们不需要单纯的白嫖用户，我们需要敢于折腾、愿意提供 Bug 反馈的硬核玩家，以及热爱底层技术的开源开发者。

  • 内测玩家：敢于折腾，愿意提供详细的 Bug 反馈与体验建议，提前尝鲜未发布的功能。
  • 开发者：擅长 C# / WPF，或者对 P2P 打洞、系统底层 API 有研究，参与 Basalt 等底层工具开发。
  • UI / 视觉设计：对暗黑风、极简风有独特理解，愿意参与界面打磨与图标设计。
  • 社区运营：维护玩家社群，整理文档与教程，帮助更多新人了解极客文化。
